# Your first 15 minutes

Learn the full route through Event Sales before you enter your first live booking.

## 1. Open the right app

In Salesforce, open the **App Launcher**, search for **Event Sales**, and select it. Confirm that the app name at the top says Event Sales. Its Home page includes your tasks, open opportunities, and event calendar.

[Tour the workspace →](./workspace)

## 2. Find the customer before creating one

Search **Accounts** for the customer. A company usually uses a Business Account with a related person as the Primary Contact. An individual customer may use a Person Account. Search existing records before adding another account or contact.

[Accounts & contacts →](./accounts-contacts)

## 3. Create the opportunity

From Home, select **New Event Opportunity**. Add the account, a short Event Title, Division, Season, Close Date, and Event Category. Select a related Primary Contact for a business customer. Start at **Interested** when the inquiry is still being qualified.

A date is optional at Interested; it becomes required at Quoted and later active stages. Save, then review the generated opportunity name.

[Create an opportunity →](./create-opportunity)

## 4. Check the location and follow-up

Use **Event Locations** to select every space the event uses and identify one Primary Event Location. Check the calendar before placing a hold. Write a specific **Next Step** and set a **Follow-Up By** date; create a task when someone needs to own an action.

[Locations & holds →](../sales/locations-holds) · [Activities →](../sales/activities)

## 5. Prepare the agreement when the details are ready

On an eligible Akron Event Sales Opportunity, find **Special Event Agreements → New Agreement**. Work through the agreement tabs, check payment totals and signer details, and preview the PDF. Review and approval come before sending.

[Agreement workflow →](../agreements/overview)

## Know these three distinctions

| These look related | What they actually mean |
| --- | --- |
| Stage and Booking Status | Stage tracks the sale; Booking Status tracks the space reservation. |
| Close Date and Event Date | Close Date is the sales close date; Event Date is when the event takes place. |
| Ready to Send and Out for Signature | Ready to Send means prepared and approved; Out for Signature means Adobe has confirmed the signing request is active. |

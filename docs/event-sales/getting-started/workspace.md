# Open your workspace

Use the **Event Sales** app for the event workflow and agreement workspace.

## Open Event Sales

1. Select the **App Launcher** in the upper-left corner of Salesforce.
2. Search for **Event Sales** and open the app.
3. Select **Home**.
4. Choose **My Data** for your work or **Team Data** for the team view available to you.

## What lives where

| Navigation item | Use it for |
| --- | --- |
| Home | Daily tasks, open opportunities, FY2027 metrics, and the embedded calendar |
| Opportunities | The sales pipeline and event bookings |
| Special Event Agreements | Contract workspaces you are allowed to access |
| Event Calendar | Date and location planning in month or list view |
| Tasks | Assigned follow-up and open actions |
| Email Templates | Reusable email content available to you |
| Contacts / Accounts | People and customer relationships |
| Campaigns | Campaign-related customer work |
| Reports / Dashboards | Detailed lists, totals, and team analysis |

A narrow window may move some navigation items into an overflow menu.

## Choose the right scope

**My Data** uses your ownership. **Team Data** applies division and record-access rules. Team Data does not grant extra access. An administrator with no Division can see a broader team view than a seller.

The home page starts in Team Data. The scope control changes the home cards, work previews, and embedded calendar. Follow a **View all…** link and check the destination list’s own filters: a list view has its own scope.

## If the screen looks different

First check the app name. Opening an agreement while using another app can show a generic record page. Switch to Event Sales and reopen it. If the app or agreement workspace is still missing, use the [access checklist](../administration/access).

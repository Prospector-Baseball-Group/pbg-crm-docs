# Handle BEO revisions

Edit the current **Draft** directly. Once a BEO is **Issued** or **Accepted**, use a revision so the earlier document and approval remain intact.

## Start a revision

1. Open the current BEO from the Opportunity, Event Agreement, or **Current BEOs** list.
2. Open **Approval & Documents**.
3. Under **Create a revision**, enter a clear **Revision reason**, such as “Guest guarantee increased; update buffet quantities and staffing.”
4. Select **Create revision**.
5. Confirm that the new record is **Draft** and its version number has increased.

<p class="caption">Demonstration record: the prior version remains Accepted, with its recorded test approval and issued PDF. Enter the reason before creating the next version.</p>

## What carries forward

The new Draft copies the event and operational details and the detail rows from the previous BEO. It keeps the connection to the source Opportunity and agreement. It does not recopy later edits from either source.

The new version clears internal approval, customer acceptance, and issued-PDF information so the revised document goes through review again. The old version retains its issued PDF and approval history. Supporting attachments remain on their original record; attach any files needed with the new revision.

<p class="caption">The new Draft retains the operational rows and becomes the current BEO. Earlier issued content is preserved.</p>

## Complete the revision

1. Make the required changes in **Event & Operations** and **Timeline & Details**.
2. Save and review the new draft PDF.
3. Complete internal review and resolve the **Approval & Documents** checklist again.
4. Select **Issue BEO & Save PDF**.
5. Share the revised PDF with the customer and operating team through the approved process, clearly identifying the version that replaces the earlier operating plan.
6. Record approval for the new version after receiving it.

Only the current issued or accepted version offers **Create revision**. If you are looking at an older version, return to the source record’s BEO card or the **Current BEOs** list. The source card lists versions so you can still open an earlier record and its **View issued PDF** control.

## When the agreement also needs to change

A BEO revision does not amend the signed Event Agreement, change the Opportunity, or reserve a different location. If the change affects contracted services, dates, spaces, or customer commitments, follow the [agreement correction workflow](../agreements/cancel-correct) and [location workflow](../sales/locations-holds) as well.

The BEO’s start date comes from its source at creation. If the booking is rescheduled to a different start date, correct the underlying booking and agreement through the appropriate process, then create or open the BEO for that date. Review the existing BEOs with the operating team so an outdated plan is not used.

# Banquet Event Orders

A **Banquet Event Order (BEO)** gives the event team one operational plan for menus, rooms, timing, staffing, equipment, and service instructions. Usually, create it after the Event Agreement is signed. Existing event and agreement details are copied so you can complete the operating plan without entering everything again.

## Choose your starting point

| Start from | What happens |
| --- | --- |
| [Event Agreement](./create#from-an-event-agreement) | Uses the agreement version you opened and its event date. This is the clearest route after signing. |
| [Opportunity](./create#from-an-opportunity) | Uses the current agreement matching the Opportunity’s event date, when one exists. Otherwise, copies the Opportunity’s available details. |
| [Banquet Event Orders → New](./create#from-the-banquet-event-orders-tab) | Lets you select an Event Sales Opportunity, then follows the same creation rules as the Opportunity route. |

All three routes open the existing current BEO for the same Opportunity and event date if one already exists. **Create / Open BEO** does not create a revision or duplicate an existing order.

## Work through the BEO

1. [Create or open the BEO](./create) and review the copied information.
2. [Complete operations and detail rows](./prepare-issue), save, and review the draft PDF.
3. Resolve the **Approval & Documents** checklist and select **Issue BEO & Save PDF**.
4. Record customer approval after receiving it.
5. [Create a revision](./revisions) for changes to an issued or accepted version.

| Status | What you can do |
| --- | --- |
| Draft | Edit and save the current BEO, add or remove details, and preview the draft. |
| Issued | View the saved PDF, record customer approval, or start a revision. The issued content is frozen. |
| Accepted | View recorded approval and the saved PDF, or start a revision. |

## Shared across clubs

Each club can describe its own menus, rooms, setup, staffing, and pricing using the same fields and repeatable detail rows. BEOs do not require the Akron agreement template. An Event Agreement still depends on an available template for its division.

BEOs store an operational snapshot. Later changes to the Opportunity or agreement do **not** automatically replace the BEO’s contents. Editing a BEO does not change the agreement. Review both documents if a change affects the customer’s contractual commitments.

## Access and verification

Use the **Event Sales** app and the **Banquet Event Order User** permission set. Creating, editing, issuing, recording acceptance, and revising also require edit access to the source Opportunity. Ask your administrator if the tab or workspace is missing.

# Lists, reports & dashboards

Use lists to work records and reports to explain the business. Always check the filters before comparing totals.

## Work an opportunity list

1. Open **Opportunities**.
2. Select an Event Sales list view appropriate to your work, such as **My Open Event Opportunities** where available.
3. Confirm record type, owner scope, stage, and date filters.
4. Open a record to review or update it.
5. Refresh the list after changes when needed.

The Home **View all open opportunities** link takes you to an owner-filtered Event Sales list. It does not automatically reproduce a Team Data summary. Check the list’s own filters after navigation.

If inline editing is unavailable, open the record and use Edit. Available inline fields depend on the list, field type, record type, and your permissions.

## Use a report

1. Open **Reports** and find the report or appropriate folder.
2. Review the date field as well as the date range.
3. Check Division, owner scope, record type, and stage/status filters.
4. Run or refresh the report.
5. Open individual records to investigate differences.

For unsuccessful events, use **Event Sales Reports → Event Sales Lost & Turned Down**. Its summed Amount represents estimated opportunity value, not collected revenue.

## Compare dates correctly

| Field | Question it answers |
| --- | --- |
| Close Date | When did, or will, the sale close? |
| Event Date | When does the event happen? |
| Season | Which fiscal season is assigned? |
| Agreement Effective Date | When is the agreement effective? |
| Payment Due Date | When is that payment due? |

These fields are not interchangeable. Native fiscal-year filters based on Close Date can produce different results from the Event Date-based home cards.

## Dashboards and access

Open **Dashboards**, select a dashboard you can access, and check its filters and refresh state. Its running-user and sharing setup can affect what you see. A missing folder or report may be an access issue; a visible report with no rows may be a filter or record-access issue.

For a discrepancy, send the administrator the report name, selected filters, comparison total, and a specific example record through your internal channel. Keep customer examples out of public GitHub issues.

# Handle incoming inquiries

An inquiry should become one clear customer conversation, with one owner and an explicit next action.

## Check for an existing opportunity

Search the account and opportunity list for the customer, requested event date, and event title. A connected inquiry source such as Eventective can already have created an Event Sales Opportunity. Avoid creating another copy for the same inquiry.

## Review a synced inquiry

1. Open the opportunity and confirm the customer and assigned owner.
2. Read the imported description and customer requirements.
3. Verify the event date, category, type, attendance, contact details, Division, and Season.
4. Check whether a task already exists.
5. Record your response and set the next step.

A source label describes where the inquiry came from. It does not establish that an acknowledgement email was delivered.

## Add an inquiry manually

Use **New Event Opportunity** and start at Interested if the event is still being qualified. Enter only confirmed details. Leave an unknown Event Date blank at this stage rather than entering a made-up date.

## Use a short qualification checklist

- What is the purpose of the event?
- Which date, start and end times, and locations are needed?
- What is the expected attendance?
- Who coordinates the event, and who can sign the agreement?
- What services, food and beverage, or additional access are needed?
- What follow-up has been promised, and by when?

Keep the answers in the opportunity’s event requirements, description, and activities. Move to Quoted after the event date is known and the quote has been provided.

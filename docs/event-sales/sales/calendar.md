# Use the event calendar

Open **Event Calendar** from the Event Sales navigation. Home also contains a compact calendar.

## Find an event

1. Choose the relevant month with **Previous month**, **Next month**, or **Today**.
2. Set **Booking status**.
3. Choose an **Event space**, or leave **All spaces** selected.
4. On the standalone calendar, use **Only my events** when you want your own records.
5. Select **Month** for a date grid or **List** for a compact list.
6. Select an event to open its opportunity.

The embedded Home calendar follows the Home My Data / Team Data selection instead of showing its own ownership toggle.

## Read “All active” correctly

**All active** includes **Not Held**, **Tentative Hold**, and **Booked**. Even though the card is titled Held and Booked Calendar, a Not Held event can appear. Read each event’s status before treating it as a reservation.

A multi-location event can be found by filtering to any of its selected spaces. The list can display more than one location for the same event.

## If an event is missing

Check the month, Event Date, booking-status filter, space filter, ownership scope, division, and record access. An undated inquiry cannot be placed on a calendar date. Released events are not part of the All active view.

## Before promising availability

Review all required locations and confirm the time window on the opportunity. A calendar is a planning view, and Salesforce conflict checks also run when reservations are saved. Use both before confirming a hold.

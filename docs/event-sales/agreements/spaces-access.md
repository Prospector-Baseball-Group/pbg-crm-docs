# Spaces & access

Use **Spaces & Access** for two different parts of the event: the locations where it happens and the additional areas the customer may access.

## Event Locations

These locations are copied from the opportunity. One is identified as Primary. Multiple locations belong to the same agreement and appear in its generated document.

To change them on an unlocked Draft:

1. Select **Edit on Opportunity**.
2. Update and save **Event Locations** on the opportunity.
3. Return to the agreement and select **Refresh from Opportunity**.
4. Check every copied location before generating a new preview.

Do not use Additional Access Areas as a substitute for booking an event location.

## Add an Additional Access Area

1. Choose the approved **Facility area**.
2. Select **Add Area**.
3. Choose the appropriate **Access** status.
4. Enter clear customer-facing **Access Detail**, including any conditions or limits.
5. Leave the field to allow its save and check for errors.
6. Use **Move up / Move down** to arrange rows if needed, or **Remove** to remove an area that is not included.

New agreements begin with no additional access rows. Add only the areas approved for this event. Duplicate areas are blocked. **Conditional** access requires Access Detail.

## Write detail that can go into the contract

For a fictional example: “Access to the west gate for guest arrival from 5:30–6:30 p.m.; event staff will direct entry.” Use the event’s actual approved arrangement before sending.

These details appear in the generated agreement. Avoid internal shorthand or instructions intended only for staff.

## Check the preview

Confirm the location list, Primary designation, and additional-access table. A change made after an earlier PDF was generated requires a new preview; it does not rewrite the earlier copy.

# Track signatures & files

Use **Documents & Signatures** to follow the current signature request. Read the agreement and document statuses together.

## Focus on the current document

The top card shows **Current agreement** or **Signed agreement**, with **Open PDF**. The current request shows just the two signers: **Akron signer** and **Customer signer**. **Awaiting signature** identifies the current turn; **Up next** identifies the following signer. Open **Earlier documents** only when you need a prior copy.

The document badge uses simple labels such as **Not sent**, **Sending…**, **Not sent — needs attention**, **Awaiting signatures**, **Signed**, and **Cancelled**. The agreement’s status strip uses the workflow statuses below.

## Read the status

| Status | What it tells you | Next action |
| --- | --- | --- |
| Draft | Agreement details are being prepared | Complete the tabs and preview |
| Internal Review | Submitted for review | Review and approve when appropriate |
| Ready to Send | Approved for the sending step | Verify recipients, then send |
| Sending / processing | A request is being processed | Wait and sync the same request |
| Generated / unsent authoring | A copy exists but sending is not confirmed | Inspect the error or sync; do not assume delivery |
| Out for Signature | Adobe has confirmed an active signing request | Follow signer progress |
| Executed | Adobe completion has been recorded on the agreement | Verify returned signed files and handoff |
| Declined | A recipient declined | Review with the customer and manager |
| Expired | The request expired | Confirm the next agreed course of action |
| Voided | The agreement/request has been voided | Preserve history and follow the correction process |

Some labels apply to the document while others apply to the agreement. A PDF’s presence alone does not establish execution.

## Refresh signature status

Select **Refresh status** on the current document, or **More agreement actions → Sync Adobe Status**, when a request exists. Automatic status checks are also scheduled, so Salesforce may not change immediately after a signer acts. If the status remains unclear, ask the administrator to reconcile the existing request before retrying.

## Find the completed documents

After confirmed completion, use **Open PDF** on the **Signed agreement** card and **Download audit trail**. Verify that you have the executed PDF rather than an earlier preview. Earlier copies remain in the collapsed **Earlier documents** section.

If either returned file is missing, sync and report the missing artifact. Do not label an unsigned preview as the executed agreement.

## Keep the opportunity and event plan current

Confirm the Opportunity’s Stage and Booking Status reflect the actual sale. Do not assume agreement execution automatically completes every opportunity update, task, invoice, or operational handoff.

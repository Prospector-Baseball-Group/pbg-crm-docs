# Access and onboarding

This page helps managers and administrators request the right access. Sellers should use their normal assigned account and ask for assistance when a required action is unavailable.

## Standard Ticket Sales access

The current access model separates:

| Access area | Purpose |
| --- | --- |
| Ticketing | App and base Ticket Sales access |
| Ticket Sales Home | Access to the personalized homepage |
| Ticket Sales Home Manager | The permission-controlled Team view toggle |
| Ticketing Agreement access | Agreement workspace, records, and integration permissions needed for the workflow |
| Record sharing | Which customer and Opportunity records the user can actually read or edit |
| Report/dashboard folders | Which saved analytics the user can open |

An app appearing in the launcher does not prove every record or action is accessible. A manager permission does not replace record sharing.

## Onboard a seller

1. Confirm the person's Salesforce user, division, and appropriate app access.
2. Open Ticketing and verify Home loads.
3. Verify access to an appropriately assigned Account and Opportunity.
4. Confirm the seller can create/edit the intended record types and log activities.
5. Check report and template folders needed for the job.
6. If agreements are required, verify the Opportunity, agreement, and integration permissions with an approved internal test.
7. Walk through [Your first 15 minutes](../getting-started/quick-start.md).

Do not give broad administrative rights simply to fix one missing action. Verify the exact user, record, action, and assigned access.

## What to include in an access request

Provide the user's name, team/division, record or report link, action needed, exact error, and a known-good peer who can perform it. The administrator should compare effective access to that same record, not just permission-set names.

For an agreement error mentioning **User External Credential**, include the exact error and Opportunity link. It can be an integration-permission issue; it does not mean the seller should create a new customer or contract.
